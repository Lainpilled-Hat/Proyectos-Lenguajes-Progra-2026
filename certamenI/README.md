# Tecnologías usadas:
- Python
- Makefile
- lark


# Modo de Uso:

En el directorio ./certamenI, ejecutar el siguiente comando:

```
make [VENV] [INPUT1] [INPUT2] run
```
Ejemplo de uso:
```
make VENV=lenguajesprogra INPUT1=./ejemplo.tm INPUT2=1011  run 
```

Otros comandos:
```
make help
make
make [VENV] clean
```
